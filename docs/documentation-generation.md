## 📖 概述

本项目使用 **dartdoc** 工具生成 API 文档，并通过 GitHub Pages 进行部署。文档生成脚本专门针对 Windows 系统的文件路径限制进行了优化。

### 🎯 主要特性

- ✅ **多包支持**：主应用、listen_core、listen_uikit
- 🔄 **智能复制**：处理 Windows 路径长度限制
- 🎨 **美观界面**：现代化导航页面
- 📱 **响应式设计**：适配各种设备
- 🔍 **状态指示**：实时显示文档可用性

### dartdoc_options.yaml 配置

`dartdoc_options.yaml` 是 dartdoc 工具的配置文件，用于自定义文档生成的行为和外观。

#### 🎯 **主要作用**

| 功能 | 说明 |
|------|------|
| ⚙️ **生成配置** | 控制文档生成的各种选项 |
| 🎨 **样式定制** | 自定义文档的外观和主题 |
| 📝 **内容控制** | 决定哪些内容被包含在文档中 |
| 🔗 **链接管理** | 配置外部链接和交叉引用 |
| 📊 **元数据** | 添加项目信息和版本号 |

#### 📁 **配置示例**

```yaml
# dartdoc_options.yaml
dartdoc:
  # 基本配置
  linkTo: 
    url: https://github.com/listen2code/ListenPortfolioFlutter
    text: "GitHub Repository"
  
  # 页面配置
  favicon: assets/favicon.png
  footerText: "Generated by dartdoc"
  
  # 包含/排除
  include:
    - lib/
  exclude:
    - lib/src/generated/
  
  # 格式化
  showUndocumented: false
  showInherited: true
  
  # 主题
  theme:
    name: "default"
    useSideBar: true
```

#### ⚙️ **常用配置选项**

| 选项 | 类型 | 说明 |
|------|------|------|
| `include` | List | 包含的目录列表 |
| `exclude` | List | 排除的目录列表 |
| `showUndocumented` | bool | 显示未文档化的内容 |
| `showInherited` | bool | 显示继承的成员 |
| `favicon` | String | 网站图标路径 |
| `footerText` | String | 页脚文本 |
| `linkTo` | Map | 外部链接配置 |

#### 🎨 **自定义主题**

```yaml
dartdoc:
  theme:

    useSideBar: true
    font:
      family: "Inter, sans-serif"

```

#### 📝 **实际项目配置**

对于 Listen Portfolio Flutter 项目，推荐的配置：

```yaml
dartdoc:
  # 项目信息
  name: "Listen Portfolio Flutter"
  version: "1.0.0"
  description: "Flutter portfolio application with clean architecture"
  
  # 链接配置
  linkTo:
    url: https://github.com/listen2code/ListenPortfolioFlutter
    text: "View on GitHub"
  
  # 包含配置
  include:
    - lib/
    - packages/listen_core/lib/
    - packages/listen_uikit/lib/
  
  # 排除配置
  exclude:
    - lib/src/generated/
    - lib/**/*.g.dart
    - lib/**/*.freezed.dart
  
  # 显示选项
  showUndocumented: false
  showInherited: true
  categorizeUndocumented: false
  
  # 输出配置
  output: "docs/pages"
  canonicalPrefix: "https://listen2code.github.io/ListenPortfolioFlutter/pages"
  
  # 样式配置
  favicon: "assets/favicon.png"
  footerText: "© 2026 Listen Portfolio Flutter Team"
  
  # 主题配置
  theme:
    name: "default"
    useSideBar: true
    showNavbar: true
    showFooter: true
```

```bash

# 指定配置文件

# 覆盖特定选项

```

## 📜 脚本说明

### generate_docs.ps1

这是主要的文档生成脚本，具有以下特性：

#### 🎯 核心功能

1. **依赖检查**：验证 Dart 和 dartdoc 安装
2. **多包生成**：同时生成主应用和子包文档
3. **智能复制**：处理 Windows 路径限制
4. **状态跟踪**：实时显示生成进度
5. **自动清理**：清理临时文件

#### 📁 目录结构

```
scripts/
├── generate_docs.ps1          # 主要文档生成脚本
└── ...                        # 其他历史脚本
```

#### ⚙️ 脚本配置

脚本中的关键配置项：

```powershell
# 输出目录
$GhPagesDir = Join-Path $ProjectRoot "pages"

# 临时目录
$TempMainDir = Join-Path $ProjectRoot "doc_main_$((Get-Date).ToString('yyyyMMdd_HHmmss'))"
$TempCoreDir = Join-Path $ProjectRoot "doc_core_$((Get-Date).ToString('yyyyMMdd_HHmmss'))"
$TempUIKitDir = Join-Path $ProjectRoot "doc_uikit_$((Get-Date).ToString('yyyyMMdd_HHmmss'))"
```

## 🌐 GitHub Pages 设置

### 1. 配置 GitHub Pages

#### 通过 GitHub Web 界面设置

1. 🌐 **访问仓库设置**
   - 打开 GitHub 仓库
   - 点击 **Settings** 标签
   - 在左侧菜单找到 **Pages**

2. ⚙️ **配置部署源**
   ```
   Source: Deploy from a branch
   Branch: main
   Folder: /pages
   ```

3. 💾 **保存设置**
   - 点击 **Save**
   - 等待几分钟后生效

#### 设置说明

| 选项 | 推荐值 | 说明 |
|------|--------|------|
| Source | Deploy from a branch | 从分支部署 |
| Branch | main | 主分支 |
| Folder | /pages | 文档目录 |

### 2. 验证部署

- 🌐 **访问地址**：`https://listen2code.github.io/ListenPortfolioFlutter/pages`
- ⏱️ **生效时间**：通常 1-10 分钟
- ✅ **检查链接**：确认所有文档链接正常

### 3. 分支管理

#### 🎯 **推荐使用 main 分支**

**优势**：
- ✅ **简化流程**：无需管理多个分支
- 🔄 **自动部署**：推送即自动更新
- 📁 **统一管理**：代码和文档在同一分支

**工作流程**：

## 🔧 故障排除

### 常见问题

#### 1. Windows 路径长度限制

**问题**：文件路径过长导致复制失败

**解决方案**：
- ✅ 脚本已内置智能复制策略
- 🔄 自动降级到部分复制
- 📁 只复制核心文件

#### 2. dartdoc 依赖缺失

**问题**：`dartdoc dependency not found`

**解决方案**：
```yaml
# 在 pubspec.yaml 中添加
dev_dependencies:
  dartdoc: ^9.0.0
```

#### 3. 文件锁定错误

**问题**：文件被占用无法删除

**解决方案**：
- 🔄 重启 PowerShell
- 🧹 使用 `git clean` 清理
- ⏰ 等待几分钟后重试

#### 4. GitHub Pages 404 错误

**问题**：文档部署后出现 404

**解决方案**：
- 📁 检查 `index.html` 是否存在
- 🔗 验证链接路径是否正确
- ⏱️ 等待 DNS 传播完成
