CommonWebView 测试与调试中心

通过操作各个测试卡片，您可以验证并观察 CommonWebView 的各项 API、拦截器及混合桥接机制的触发与表现。

高度自适应测试 shrinkWrap

动态调整 HTML 文档的高宽。当开启 shrinkWrap 时，H5 高度变化会实时通过 resize 桥接通道回传，自动缩放 Flutter 容器，若高度超出 maxHtmlHeight 限制则会出现原生滚动条。

标题动态修改 onTitleChanged

点击下方按钮修改 document.title。在 Flutter 侧如果未显示设置 title 属性，AppBar 标题应该会自动监听并跟随 H5 Title 同步更新。

JS 调用 Flutter javascriptHandlers

通过 InAppWebView 的 callHandler 机制将数据从 H5 传递给 Flutter。可以同步或异步等待 Flutter 侧执行并回传数据，实现双向桥接。

点击“获取设备信息”按钮，Native 执行结果将在此回显。
