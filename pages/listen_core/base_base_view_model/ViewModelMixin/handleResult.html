Helper method to handle Either results.

This method provides a convenient way to process Either results from use cases or other operations that return Either<Failure, T>.

T is the success type. result is the Either result to handle. onFailure is an optional callback for handling failures. onSuccess is the callback for handling successful results.

Example:

final result = await _getUserUseCase.execute(userId);
await handleResult(
  result,
  onSuccess: (user) => updateState(state.copyWith(user: user)),
  onFailure: (failure) => emitEffect(MessageEffect.error(failure.message)),
);
