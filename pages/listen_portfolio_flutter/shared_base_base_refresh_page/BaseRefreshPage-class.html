BaseRefreshPage

BaseRefreshPage<V extends BaseViewModel, S extends BaseState> class

A shared-layer wrapper for the core BaseLifeCyclePage. This widget acts as a bridge between business-specific Riverpod providers and the pure core architecture, keeping BaseLifeCyclePage independent.
