📋 内测包验证前置准备 测试必读
为什么需要内测邀请？ Google Play 的 Install Referrer API 在用户从真实 Store 页面点击“安装”时会记录并在应用首次启动时下发参数。对于内测包（内部测试/封闭测试），测试手机的 Google 账号必须先接受测试邀请，否则打开详情页会显示“找不到此内容”。
  1. 第一步：加入内测测试计划
    测试账号在手机浏览器或电脑上访问您的内测邀请链接（形如：https://play.google.com/apps/testing/com.listen.portfolio.listen_portfolio_flutter），点击【成为测试人员 (Become a Tester)】。
  2. 第二步：确保测试手机卸载现有 App
    Install Referrer 只在新安装或全新首次启动时下发。如果手机上已有调试版，请先完整卸载。
  3. 第三步：点击下方生成的测试链接
    在手机浏览器中打开本测试页面，点击【直接跳转 Google Play 商店】或直接扫码进入。
  4. 第四步：在 Google Play 页面点击安装并打开
    安装完成后直接打开应用，App 首次启动将自动弹出欢迎卡片并显示您配置的来源名称与直达模块！
